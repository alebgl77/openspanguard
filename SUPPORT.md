# Support

OpenSpanGuard is a Developer Preview with best-effort community support. Start with the [quickstart](README.md#try-the-demo), [FAQ](docs/faq.md) and [troubleshooting](docs/troubleshooting.md).

| Need | Where to go |
| --- | --- |
| Setup question, design discussion or use-case feedback | [GitHub Discussions](https://github.com/alebgl77/openspanguard/discussions) |
| Integration success, incompatibility or blocked setup | [Integration report](https://github.com/alebgl77/openspanguard/issues/new?template=integration_report.yml) |
| Reproducible defect | [Bug report](https://github.com/alebgl77/openspanguard/issues/new?template=bug_report.yml) |
| Workflow gap or feature proposal | [Feature request](https://github.com/alebgl77/openspanguard/issues/new?template=feature_request.yml) |
| Vulnerability or sensitive disclosure | [Security policy](SECURITY.md) |

For public reports, include the version/commit, OS and Node/Docker versions, exporter package and transport, evaluator mode, minimal synthetic reproduction and observed result. State which checks you actually ran. Remove credentials, real prompts, responses, user identifiers and private endpoints from logs or configuration before sharing.

Please keep unrelated problems in separate reports and follow the [code of conduct](CODE_OF_CONDUCT.md). There is no support SLA or general production-readiness guarantee. Review the [production checklist](docs/production-checklist.md) before a canary or deployment with sensitive data.
