# First 90 days

These are sequencing goals after preview release, not delivery promises.

| Period | Work | Exit evidence |
| --- | --- | --- |
| Days 1–30 | Three distinct app integrations, privacy review, human-labeled dataset and overhead/cost/loss baselines | Reproducible integration notes, failure cases and candidate calibrated thresholds |
| Days 31–60 | Saturation/replica tests, persistent collector queue assessment, timeout/coverage refinement, protocol ADR | Failure-injection reports, load profiles and reviewed architecture decisions |
| Days 61–90 | Expand canaries, rollback/credential drills, release and supply-chain review | Calibration report, operational runbook and explicit production go/no-go |

Possible later work: standard evaluation LogRecord export, more scorer adapters, a stable packaged SDK and distributed replay suppression. None is a current feature.
